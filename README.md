# 小红书 KPOP 店铺 · 每周经营数据看板

> 一个面向小红书（千帆）店铺主的**本地化、零依赖、可每周自动跑**的经营数据看板。
> 把千帆后台导出的订单 Excel 丢进文件夹，一键生成韩系磨砂玻璃风格的可视化看板 + 可复制的月度/季度报表。

---

## ✨ 项目简介

店主在小红书经营一家主营 KPOP 专辑 / 小卡 / 官娃 / 摆件的网店（店名「sleep 的店」）。
本仓库是一套**纯 Python 生成、自包含 HTML 看板**的方案，解决"每周手动看数据太累、千帆后台图表不够细"的痛点。

- 无需联网、无需数据库、无需部署服务器
- 全部数据留在本地（适合私密经营数据）
- 视觉走**韩系低饱和 + 磨砂玻璃**风格，信息层级清晰

## 🎯 功能特性

| 模块 | 说明 |
|------|------|
| **宏观大盘** | 净 GMV / 订单数 / 付费用户 / 客单价 / 取消率 / 售后率 / 复购率 / 预售占比，8 张 KPI 卡 + 月度/周度趋势图 |
| **订单结构** | 各 KPOP 团体 GMV 对比柱状图、经营健康度红灯、现货 vs 预售对比表 |
| **固定报表输出** | 月度汇总表（可选中 `Ctrl+C` 直接粘进 Excel）+ 季度汇总表 + 下单时段分布 + 下单周几分布；额外导出 `report_YYYYMMDD.xlsx` |
| **销售热点** | 本周热销 SKU 关键词、上周具体订单明细、TOP 商品 / 地域 / 团体表 |
| **下单行为分析** | 统计用户在一周中**周几**、**什么时间段**（凌晨/上午/下午/晚上/深夜）下单，辅助决定上新与内容发布时间 |

## 🚀 使用方法

### 1. 准备环境
脚本用系统 Python 3.9（自带 `pandas` + `openpyxl`）。无需 `pip install`。

### 2. 每周刷新（标准流程）
千帆后台导出当周订单 Excel → 放进 `每周订单数据/` 文件夹，然后运行：

```bash
python update_weekly.py "每周订单数据/7.27-8.2.xlsx"
```

脚本会：
1. 用**兼容内联字符串**的读取器解析周切片（详见下方「数据源说明」）
2. 按订单号识别重叠订单，用新导出覆盖旧状态（保留多 SKU 多行结构）
3. 合并进 `累计订单数据.xlsx`
4. 自动重新生成看板

### 3. 仅重新生成看板（数据没变时）
```bash
python weekly_dashboard.py
```
无参数运行时，自动读取 `累计订单数据.xlsx` 重新出图。

### 4. 自动跑（推荐）
已配置**每周一 09:00** 的定时任务：自动跑脚本并向你汇报周环比。
若数据超过 7 天没更新，会提醒你先从千帆导出最新订单再合并重跑。

## 📊 数据源说明（踩过的坑，务必看）

千帆后台导出的订单 Excel 有几个**反直觉的坑**，脚本已逐一兼容：

1. **「合计」假数据行**：导出表末尾常有订单号为空的「合计」行（金额填了总 GMV），会被误当成真实订单 → 脚本按「订单号为空」剔除。
2. **周切片是内联字符串格式**：部分周导出把所有单元格存成 `t="inlineStr"`，且 `<dimension>` 元数据错误，导致 `pandas.read_excel` 只能读到 1 个空单元格 → 脚本改用 `openpyxl` 强制全量迭代 + 数值列转数字。
3. **全量文件含透视表**：`openpyxl` 直接读会崩，但 `pandas` 能读 → 读取器采用「pandas 优先、异常时回退 openpyxl」。
4. **合并 bug（已修）**：一个订单可能含多个 SKU 行（多行）。合并时不能用「按订单号去重」（会压行丢金额），而是**把重叠订单号在旧数据里的所有行整段删除、换成新导出行**。

## 📐 指标口径

| 指标 | 定义 |
|------|------|
| **净 GMV** | 已支付（剔除「已取消/已关闭」）的 `商家应收金额` 合计 |
| **付费用户** | 去重后的 `用户编号` 数（只看真正花钱的人） |
| **客单价** | 净 GMV ÷ 已支付订单数 |
| **取消率** | 取消订单数 ÷ 全部下单订单数 |
| **售后率** | 售后完成单数 ÷ 已支付订单数 |
| **复购率** | 有 ≥2 笔订单的用户数 ÷ 全部付费用户数 |
| **预售占比** | 预售类型订单的 GMV ÷ 净 GMV |

> 注：报告里偶尔会出现「全量 286 人」的口径（含未成交），与看板「付费用户 204/216 人」不冲突，只是口径不同。

## 🎨 设计理念

- **磨砂玻璃质感**：极低饱和绿灰渐变底 + SVG `feTurbulence` 噪点纹理 + 双径向光斑 + 面板 `backdrop-filter: blur`
- **低饱和韩系色系**：全局统一柔和浅色，图表用细线（1.5px）+ 极淡填充，去掉网格线
- **信息层级**：四段式（宏观大盘 → 订单结构 → 固定报表 → 销售热点），带编号 section 标题拉开层次
- **圆形悬浮点位卡片**：KPI 用白色 60% 透明 + 模糊悬浮卡片，图表面板用圆角矩形悬浮卡片
